# stowage_vm_install (Data Source)

Reads a Kairos VM's `<short_name>-stow status --json --values` over SSH without managing it. Nothing on the VM changes.

## Example Usage

```terraform
# What a VM runs, read without managing it.
data "stowage_vm_install" "notes" {
  name             = "notes"
  short_name       = "notes"
  host             = "192.0.2.10"
  user             = "ops"
  known_hosts_line = "192.0.2.10 ssh-ed25519 AAAA..." # the VM's own key
}
```

## Details

Reads a Kairos VM's `<short_name>-stow status --json --values` over SSH, as the SSH user, without
managing it. Nothing on the VM changes. The read is bounded by 5 minutes. Another project's
install (`Another project's install`) is an error.
