# stowage_kubernetes_install (Data Source)

Reads a Kubernetes release's `k8s status --json --values` without managing it, on the cluster the provider's `kubernetes` block reaches: the installer image's entry for the machine running OpenTofu (read from the registry, checked against the release's keys) runs there, with `helm` and `kubectl`. Nothing on the cluster changes.

## Example Usage

```terraform
# What a release runs, read without managing it, on the provider's cluster.
data "stowage_kubernetes_install" "notes" {
  installer = "registry.example.com/notes/notes-installer@sha256:0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef"
  namespace = "notes"
}
```

## Details

Reads a Kubernetes release's `k8s status --json --values` without managing it, on the cluster the
provider's `kubernetes` block reaches: the installer image given is read from its registry for the
machine running OpenTofu, checked against the provider's `public_keys` when given (as `stowage_vm_seed`'s: [trust](../guides/trust.md)), and runs
there with `helm` and `kubectl` on `PATH`, in a private directory removed afterwards (the
kubeconfig written there as the resource's). Nothing on the cluster changes. The read is bounded
by 5 minutes. No release of the name (`No release`) and another project's (`Another project's
release`) are errors.
