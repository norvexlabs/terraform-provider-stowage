# stowage_docker_install (Data Source)

Reads a Docker install's `status --json --values` without managing it, by the installer it keeps (`<work_dir>/<name>/<short_name>-stow status --json --values`), on a host reached over SSH or on the machine running OpenTofu. Nothing on the target changes.

## Example Usage

```terraform
# What a Docker install runs, read without managing it (another root's install, a dashboard).
data "stowage_docker_install" "notes" {
  name             = "notes"
  short_name       = "notes"
  host             = "app.example.com"
  user             = "ops"
  known_hosts_line = "app.example.com ssh-ed25519 AAAA..."
  work_dir         = "/srv"
}

output "notes_version" {
  value = data.stowage_docker_install.notes.installed.version
}
```

## Details

Reads a Docker install's `status --json --values` without managing it, by the installer it keeps
(`<work_dir>/<name>/<short_name>-stow status --json --values`, through the same scripts as the
resource's read), on a host reached over SSH or on the machine running OpenTofu. Nothing on the
target changes, and no installer image is fetched. The read is bounded by 5 minutes. No install in
the directory (`No install`) and another project's (`Another project's install`) are errors.
