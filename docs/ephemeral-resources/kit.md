# stowage_kit (Ephemeral Resource)

The kit `stowage_kit` issued, in the same apply, for a write-only attribute: `kit_wo` and `kit_code_wo` of `stowage_*_install` or `stowage_kit_take`. Null outside the apply that issued it (a later plan, another provider configuration): the kit was kept in that apply's provider process alone. Use the same provider configuration as the `stowage_kit`.

## Example Usage

```terraform
# The kit stowage_kit.site_b issued in this apply; null in any other plan or apply.
ephemeral "stowage_kit" "site_b" {
  id = stowage_kit.site_b.id
}
```

## Details

Open runs nothing remote: it reads the kit `stowage_kit` kept in the provider's process under `id`.
OpenTofu opens it on every plan and apply that reaches it, and skips it while `id` is unknown (a
plan creating the kit): in the apply that issues the kit, the kit and its code; anywhere else
(a later plan, a later apply, another provider configuration's process), null. Its values are
sensitive and ephemeral: they reach write-only attributes alone (`kit_wo`, `kit_code_wo`).
